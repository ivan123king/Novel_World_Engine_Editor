# 说明
本软件是用来辅助写小说，当你有一些灵感、人物、物品、设定、世界地图设计时，采用传统方法不明确，所以我设计了这款软件辅助我写小说。
软件分为几个模块，
- 设定模块： 小说基础设定信息
- 人物模块： 提供人物名、经历、介绍等，可以自定义人物信息
- 物品模块： 提供物品信息记录
- 地图模块： 提供简单的地图创建
- 关系模块： 提供人物关系建立，自定义关系建立
- 剧情模块： 提供零散的剧情记录，不再丢失灵感
- 时间线： 可以创建多条时间线，整理剧情用的
