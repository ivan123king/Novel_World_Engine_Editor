# 项目首页页面设计

## 目标

项目首页只展示当前小说项目最核心的信息：

- 小说名
- 小说简介

这两个字段来自用户当前打开的小说目录中的 `novel.json`，不再使用 `mock_data/novel.json` 或其他统计假数据。

## 数据来源

首页通过 renderer 项目 store 读取当前项目状态：

```text
ProjectHome.vue -> projectStore -> projectApi -> preload IPC -> main project service -> 当前项目目录/novel.json
```

保存小说名和简介时，只更新 `novel.json` 中的 `title`、`description`、`folderPath` 和 `updatedAt`。其余未知字段必须保留，避免破坏用户手写扩展字段或未来版本字段。

## 页面布局

首页采用居中布局：

```text
右侧页面容器
└─ 居中小说信息
   ├─ 小说名
   └─ 小说简介
```

不要在项目首页展示人物数量、物品数量、剧情节点数量等统计卡片。首页是项目入口的安静信息锚点，不承担仪表盘职责。

## 编辑交互

- 小说名双击进入编辑态。
- 小说简介双击进入编辑态。
- 标题输入框失焦或按 Enter 保存。
- 简介输入框失焦保存，Enter 保留为换行输入。
- 按 Esc 取消当前编辑。
- 未打开小说项目时显示空态，提示用户通过菜单新建或打开项目。

## 非目标

第一版不实现：

- AI 建议修改简介。
- 修改前后差异弹窗。
- 富文本简介。
- 首页模块统计。
- 最近编辑资源列表。
