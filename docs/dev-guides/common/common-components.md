# 公共组件指南

## 作用

本指南记录 `src/components/common/` 下可复用组件的设计规则。后续新增或修改公共组件时，必须同步维护本文件。

开发页面前，如果需要弹框、按钮、通用输入、空状态等跨模块组件，先阅读本文件，优先复用已有组件，避免重复设计。

## 已有组件

### AppModal

文件位置：`src/components/common/AppModal.vue`

用途：通用弹框容器，适用于详情、新建、编辑等轻量覆盖式交互。

使用规则：

- 通过 `open` 控制显示隐藏。
- 通过 `title` 设置弹框标题。
- 通过 `width` 可选控制宽度，默认 `560px`。
- 通过默认 slot 放主体内容。
- 通过 `footer` slot 放底部操作按钮。
- 通过 `close` 事件通知父组件关闭。
- 支持点击遮罩和 Escape 关闭。

不要在每个业务页面重复实现弹框遮罩、标题栏、关闭按钮和基础布局。

### RichTextEditor

文件位置：`src/components/common/RichTextEditor.vue`

用途：跨模块复用的 Tiptap 富文本编辑器，适用于设定、剧情简介、说明卡片、事件内容等较长正文输入。

使用规则：

- 通过 `v-model` 读写 HTML 字符串。
- 默认 `mode="simple"`，只开放正文、二级标题、三级标题、撤销和重做。
- 剧情块、说明卡片、事件内容等大段内容优先使用默认精简模式，不开放列表、表格等复杂结构。
- 设定模块使用 `mode="setting"`，保留原有加粗、斜体、列表、引用、基础表格和中文 Tab 行为。
- 普通正文按 Tab 插入两个中文全角空格作为首行缩进；Shift+Tab 删除当前文本块开头的首行缩进。
- 通过 `disabled` 在保存过程中禁用编辑。

业务页面负责在展示前清理 HTML，只保留该模块允许的标签和属性。

## 维护规则

- 公共组件应放在 `src/components/common/`。
- 公共组件只处理通用 UI 结构，不写入具体业务逻辑。
- 业务字段、保存逻辑和数据转换放回对应模块组件或 composable。
- 修改公共组件 API 时，必须同步更新本文件。
