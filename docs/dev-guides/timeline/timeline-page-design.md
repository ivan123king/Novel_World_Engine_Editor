# 时间线页面功能设计

## 页面目标

时间线页面用于让作者在一条时间线中维护时间块，并查看、编排、编辑某个时间块下发生的事件。

页面应沿用桌面编辑器风格：信息密度适中、操作入口明确、少装饰。第一版重点是时间块和事件编辑，不扩展复杂辅助功能。

## 页面结构

```text
Timeline.vue
├─ 顶部工具条
│  ├─ 时间线下拉框
│  ├─ 新建时间线
│  └─ 当前时间线重命名、删除
├─ 左侧时间轴
│  ├─ 新建上级时间
│  ├─ 新建下级时间
│  └─ 时间块列表
└─ 右侧事件区
   ├─ 当前时间块标题
   ├─ 新建事件
   └─ 事件卡片平铺区
      ├─ 事件卡片
      ├─ 事件卡片
      └─ 事件详情弹框
```

建议布局：

```text
grid-template-columns: 280px minmax(0, 1fr)
```

顶部工具条横跨页面内容区。左侧时间轴固定宽度，右侧事件区占用剩余空间。

## 多时间线切换

顶部使用下拉框选择当前时间线。

第一版只需要：

- 展示当前项目下所有时间线。
- 切换时间线后加载对应时间块和事件。
- 新建时间线，默认名称为“新时间线”。
- 重命名当前时间线。
- 删除当前时间线时需要确认。

不要在第一版做多时间线对比、并排查看、合并或复制。

## 时间块展示

时间块是时间线的主轴节点。

时间块卡片展示：

- 时间名。
- 别名摘要，别名多于一条时用简短列表或逗号展示。

时间轴默认按倒序展示：新时间在上，旧时间在下，最底部是更早的时间。

示例：

```text
公元202年
别名：大周历46年、北境战前一年
```

时间块不展示备注，因为第一版不设计备注字段。

## 时间块交互

支持以下操作：

- 点击时间块：选中该时间块，右侧显示该时间块下的事件。
- 双击时间块：打开时间块编辑弹框。
- 新建上级时间：在当前选中时间块上方新增时间块。
- 新建下级时间：在当前选中时间块下方新增时间块。
- 拖动时间块：在左侧时间轴内上下移动，调整展示顺序。
- 时间块拖动后的顺序保存到统一 `list-order` 元数据，不写入时间块自身字段。
- 删除时间块：需要确认；删除策略由实现阶段决定，但必须避免静默删除其下事件。

新建时间块默认名称：

```text
新时间
```

用户可以在弹框中修改名称和别名。

## 时间块编辑弹框

字段只包含：

- 时间名。
- 别名列表，可多个。

弹框行为：

- 时间名必填。
- 别名可以为空。
- 别名支持新增、编辑、删除。
- 保存后更新左侧时间块展示。

不要加入备注或说明字段。

## 事件区展示

右侧事件区只展示当前选中时间块下的事件。

没有选中时间块时，展示空状态，引导用户先选择或新建时间块。

当前时间块没有事件时，展示空状态和“新建事件”入口。

## 事件卡片

事件卡片只展示轻量信息：

- 事件标题。
- 所属时间。
- 具体时间，如果作者填写。

不要在卡片上展示完整事件内容，因为事件内容可能很长。

卡片示例：

```text
边境军变
公元202年
```

事件卡片操作：

- 点击卡片本体：选中事件并高亮，不打开详情。
- 再次点击已选中的事件卡片：取消选中，后续新建事件回到列表最前面插入。
- 点击“详情”：打开事件详情弹框。
- 悬停或选中时显示编辑、删除等轻量操作。
- 拖动：调整事件在当前时间块下的位置。
- 如果某个事件已选中，点击“新建事件”会在该事件之前新建。
- 如果没有选中事件，点击“新建事件”会在当前时间块事件列表最前面新建。

## 事件拖拽

事件按单一顺序平铺展示，不分多列。

- 事件顺序从左到右、从上到下依次由新到旧。
- 拖动事件只调整同一时间块下的单一顺序。
- 拖动后保存事件布局。
- 保存失败时回滚到拖动前布局，并展示错误。

第一版不需要自动画连接线，也不做多列并列关系。

## 事件详情弹框

事件详情弹框用于新建、查看和编辑事件完整内容。

固定字段：

- 时间。
- 具体时间。
- 事件标题。
- 事件内容。
- 自定义 `key/value`。

字段规则：

- 时间默认等于当前选中的时间块，创建事件时不允许修改。这个时间是事件所属的时间点。
- 具体时间由用户输入，例如时间块是“公元202年”，具体时间可以填写“3月”。
- 事件标题必填。
- 事件内容可以很长，使用公共精简富文本组件，只保留标题和正文，支持中文写作 Tab 缩进。
- 自定义字段由作者自由添加。
- 人物、地点、物品、剧情线等信息如果需要记录，统一放进自定义 `key/value`。

详情弹框模式：

- 新建事件。
- 查看事件。
- 编辑事件。

查看模式下内容应易读，编辑模式下再显示输入控件。

## 删除规则

删除时间线、时间块、事件都需要确认。

建议规则：

- 删除时间线：确认后删除该时间线文件或标记归档，第一版可以直接删除。
- 删除时间块：如果时间块下存在事件，必须提示用户这些事件会被一并删除或要求先移动事件。
- 删除事件：确认后删除事件。

具体删除策略在实现阶段确定，但页面不能让用户误以为只删除空壳却实际丢失事件。

## 第一阶段功能清单

必须实现：

- 时间线下拉切换。
- 新建、重命名、删除时间线。
- 展示当前时间线的时间块。
- 新建上方时间块。
- 新建下方时间块。
- 编辑时间块时间名和别名。
- 时间块上下拖动排序。
- 点击时间块展示事件。
- 新建事件。
- 事件卡片只展示事件标题和时间。
- 事件详情只能通过“详情”按钮打开。
- 新建事件时，时间锁定为当前选中时间块，用户只能填写具体时间。
- 点击事件卡片可以选中高亮。
- 再次点击已选中事件卡片可以取消高亮。
- 选中事件后新建事件，新事件插入到选中事件之前。
- 未选中事件时新建事件，新事件插入到事件列表最前面。
- 事件详情弹框展示和编辑完整事件内容。
- 编辑事件自定义 `key/value`。
- 删除事件。
- 事件平铺顺序拖动。

暂缓实现：

- 自动日期换算。
- 事件关系连线。
- 事件关联实体选择器。
- 事件影响世界状态的自动同步。
- AI 生成事件。
- 多时间线对照视图。

## 验证重点

实现后至少验证：

- 切换时间线后，时间块和事件随之更新。
- 新建上方时间块出现在当前时间块上方。
- 新建下方时间块出现在当前时间块下方。
- 时间块拖拽后刷新仍保留顺序。
- 时间块顺序保存到统一 `list-order` 元数据，不写入时间块自身 `order`。
- 时间块默认倒序展示，最底部是更早的时间。
- 时间块编辑只保存时间名和别名。
- 点击时间块后，右侧只展示该时间块下的事件。
- 事件卡片只展示标题和时间，不展示长内容。
- 点击事件卡片本体不会打开详情。
- 点击事件卡片本体会选中并高亮该事件。
- 再次点击已选中事件卡片后，新建事件会插入到当前事件列表最前面。
- 点击事件详情按钮后可以看到完整事件内容。
- 新建事件时不能修改所属时间块，但可以填写具体时间。
- 选中某个事件后新建事件，新事件出现在该事件之前。
- 事件自定义字段可以新增、编辑、删除。
- 事件拖拽调整平铺顺序后刷新仍保留布局。
- 删除包含事件的时间块前有明确确认。
