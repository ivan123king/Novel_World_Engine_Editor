# AI小助手路线图与状态

## 状态维护规则

开始实现任何 AI小助手或远程AI小助手服务功能前，必须先阅读本文件。

禁止重复实现已经标记为 `[x]` 的功能。

每完成一个功能，必须立即更新本文件，把对应项从 `[ ]` 改为 `[x]`，并在必要时补充实现位置和备注。

## Phase 1：AI 服务基础架构

目标：先让 A 能稳定连接 B。

- [ ] 创建远程AI小助手服务工程
- [ ] B 提供 HTTP 服务
- [ ] B 提供 `/health`
- [x] A 配置远程AI小助手服务地址
- [x] A 可以检测远程AI小助手服务是否在线
- [ ] A 可以调用远程AI小助手服务的测试接口
- [ ] A AI小助手发送消息
- [ ] 远程AI小助手服务返回固定测试回复
- [ ] 建立 A/B API 基础协议

完成后：A 可以通过 HTTP 正常调用 B，但还没有真实 AI。

## Phase 2：项目注册与小说数据读取

- [ ] B 保存 `projectPath`
- [ ] B 可以读取小说项目目录
- [ ] B 可以读取小说 JSON
- [ ] B 可以读取小说正文
- [ ] B 可以检测项目数据变化
- [ ] B 提供项目同步接口

- [ ] A 可以显示项目 AI 服务连接状态

完成后：B 可以读取当前小说项目，但还没有完整 RAG。
