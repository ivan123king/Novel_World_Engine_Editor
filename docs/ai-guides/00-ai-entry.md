# AI 入口指南

未来 AI 在本仓库中工作时，先把这个文件作为第一份上下文阅读。

## 一句话产品定义

Novel World Engine Editor 是一个本地 Electron 桌面应用，用于维护长篇小说的世界状态、人物关系、剧情事件，以及可供 AI 写作使用的上下文。

## 正确描述方式

应该说：

> 构建一个用于 AI 辅助长篇写作的小说世界引擎编辑器。

不要说：

> 构建一个人物 CRUD 管理系统。

这两种说法的差异很重要。CRUD 应用只是在保存记录；这个工具要维护连续性、因果关系、当前状态和写作上下文。

## 核心约束

- Windows 桌面应用
- Electron + Vue3 + TypeScript
- Electron main process 通过 Node.js 访问本地文件
- JSON 文件保存在用户选择的本地项目目录中
- 默认不使用数据库
- 后续应支持多个小说项目
- 数据离开应用后仍然应该可检查、可阅读

## 核心模块

- 项目创建和打开
- 人物管理
- 物品管理
- 地点管理
- 人物关系图
- 剧情事件管理
- 时间线
- 世界状态
- 章节元数据
- AI 上下文导出
- 后续扩展：AI 分析章节，并由用户确认后更新数据
