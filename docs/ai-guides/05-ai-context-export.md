# AI 上下文导出

## 目的

导出功能用于生成可靠的 Markdown 上下文，方便复制到 ChatGPT 或其他写作模型中。

它应该回答：

- 这是什么小说？
- 当前处于哪一章或哪个时间点？
- 本次写作任务涉及哪些重要人物？
- 当前哪些事实已经成立？
- 最近发生了什么？
- AI 必须保持哪些设定不变？

## 基础输出结构

```markdown
# AI 写作上下文

小说：大乾风云
当前章节：50

## 主角

- 林辰
- 年龄：18
- 性格：谨慎、野心、重情
- 外貌：身形清瘦，左肩有旧伤，常穿青色官袍
- 当前官职：五品知府
- 武学：青云剑法小成

## 最近事件

- 第50章：平定盐税案

## 相关人物

- 赵相：敌对，强度 80
- 苏婉儿：盟友，强度 60

## 当前目标

- 进入朝堂

## 写作约束

- 保持历史逻辑一致。
- 不要在没有事件支撑的情况下改变既定人物性格。
```

## 导出选项

未来 UI 应该允许选择：

- 当前主角
- 最近事件的章节范围
- 包含哪些人物
- 包含哪些地点
- 包含哪些势力
- 是否包含人物 `customFields`
- 是否包含关系摘要
- 是否包含未完成剧情线
- 是否包含写作约束

## 确定性

同一个项目状态和同一组选项，应该导出相同的上下文。不要在本地生成器里使用随机措辞。

## 后续扩展：AI 章节分析

流程：

1. 用户粘贴或选择章节文本。
2. 应用把章节内容和当前结构化上下文发送给模型。
3. 模型返回结构化的建议变更。
4. 应用展示确认弹窗。
5. 用户逐条接受、编辑或拒绝变更。
6. 只有被用户接受的变更才写入 JSON。

模型返回结构示例：

```json
{
  "newCharacters": [],
  "updatedCharacters": [
    {
      "id": "char_linchen",
      "change": {
        "customFields.当前官职": "五品知府",
        "customFields.官职履历": [
          {
            "章节": 51,
            "官职": "五品知府",
            "原因": "第51章明确升任"
          }
        ]
      },
      "reason": "第51章明确升任"
    }
  ],
  "newRelations": [
    {
      "from": "char_linchen",
      "to": "char_huangdi",
      "type": "trust",
      "score": 80,
      "reason": "平定盐税案后获得信任"
    }
  ],
  "events": []
}
```

## 安全规则

永远不要静默应用 AI 分析结果。AI 生成的更新只是建议，必须经过用户确认后才能写入。
