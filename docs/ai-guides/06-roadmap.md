# 开发路线图

按阶段开发。不要要求 AI 一次性生成整个应用。

## 第 1 阶段：架构和数据设计

目标：

- 确认产品方向
- 定义项目 JSON 目录结构
- 定义核心 TypeScript 接口
- 定义 Electron 进程边界

交付物：

- 项目脚手架方案
- JSON schema 或 TypeScript 类型
- 基础项目目录契约

## 第 2 阶段：Electron + Vue 基础工程

目标：

- 创建可运行桌面应用
- 打开窗口
- 添加菜单
- 选择或创建项目目录
- 读取和写入项目元数据

交付物：

- Electron main/preload/renderer 结构
- 类型化 IPC API
- 基础项目首页

## 第 3 阶段：人物管理

目标：

- 管理人物 JSON 文件
- 构建列表 + Inspector UI
- 支持新增、编辑、删除、搜索

交付物：

- 人物 store/service
- 人物 Inspector
- JSON 持久化

## 第 4 阶段：人物关系图

目标：

- 可视化人物关系
- 选择节点和关系边
- 查看和编辑关系边数据

交付物：

- 关系图组件
- 关系 JSON service
- 关系边 Inspector

## 第 5 阶段：事件和时间线

目标：

- 把剧情事件作为世界事实进行管理
- 按章节显示时间线
- 把事件关联到人物、物品和地点

交付物：

- 事件编辑器
- 时间线视图
- 交叉引用展示

## 第 6 阶段：AI 上下文导出

目标：

- 从当前项目状态生成可复制的 Markdown 上下文

交付物：

- 导出选项
- Markdown 生成器
- 复制到剪贴板 UI

## 第 7 阶段：AI 章节分析

目标：

- 分析新的章节文本
- 生成建议 JSON 变更
- 让用户确认变更

交付物：

- 模型提供方抽象
- 结构化响应解析器
- 差异确认 UI
- 已接受变更写入器
